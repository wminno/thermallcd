1. The panel (per-device canvas — 1920x462 here, shown at 50%)

Default layout per D18: hierarchy by widget SIZE, nothing pinned — tier 1 hero (cpu/gpu utilization+temp), tier 2 meters (nvtop, disk, load, llm), tier 3 ambient (scene + watermark). nvtop is a movable block; resizing sets its pty size and it re-renders (D19). Widgets render in per-widget iframes (D21); stale data dims with a "stale" mark, never silent zeros (D23). Boot: the scene renders first, widgets fade in on first data (D22).
